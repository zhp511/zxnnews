# Owner Space recordings

Put MP3s (or source `.webm` files) for **@zxnbluehandus's own Spaces only** in this folder, named `<space-id>.mp3` or `<space-id>.webm`. `spaces.py` converts `.webm` to MP3 and offers a Download MP3 button on the site.

Do not put recordings of other people's Spaces here. Those stay as Listen on X only.

Keep each file under about 50 MB so it can live in the GitHub Pages repo. Larger files should go on Google Drive instead of being committed.

When the Windows PC (ZhpxnewsHQ) is online, owner recordings may also be copied from `Music\ZXN Space Recordings\*.webm`.
